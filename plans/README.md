# Plans（計画管理）

## 構造

```
plans/
├── README.md          ← このファイル（運用ルール）
├── pending/           ← 未着手・進行中の計画
└── finished/          ← 完了済みの計画
```

## 運用ルール

1. **新しい計画** は `pending/` に `YYYY-MM-DD-<slug>.md` 形式で作成する
2. **計画完了時** は `pending/` から `finished/` に移動し、完了日を記録する
3. **計画の粒度**: 1つの計画 = 1つのコミット〜1セッションで完了できる範囲
4. **大きな計画** はフェーズ分割してチェックリストで進捗管理する

## 計画ファイルのテンプレート

```markdown
# タイトル

- 作成日: YYYY-MM-DD
- 完了日: （完了時に記入）
- 優先度: HIGH / MEDIUM / LOW
- 関連: （関連する計画やissueへのリンク）

## 背景
なぜこの計画が必要か

## 実施内容
- [ ] ステップ1
- [ ] ステップ2

## リスクと対策
| リスク | 対策 |
|--------|------|

## 完了基準
- [ ] 基準1
- [ ] 基準2
```

## セッション開始時の確認事項

- `pending/` に未完了の計画がないか確認する
- 優先度 HIGH の計画を先に処理する
- 完了した計画は速やかに `finished/` に移動する
