# 意思決定: GitHub Issueによる全社PDCA・情報共有プロトコル導入

## 背景
オーナーより、会社方針としてGitHub Issueを使った全社的な情報共有およびPDCAサイクルの運用を導入したいとの指示。社内プロトコルとして策定する。

## 判断内容
- 全部署のタスク・情報共有・PDCAをGitHub Issueで統一管理する
- ラベル体系: PDCA フェーズ × 部署 の組み合わせ
- 対象リポジトリ: `yukiko10140422-star/trustport`（COMPANY）
- .company/ 内のローカル管理と GitHub Issue の併用体制

## 振り分け先
| 部署 | 指示内容 |
|------|---------|
| PM | ラベル体系の設計・GitHub上への実装 |
| 秘書室 | プロトコル文書の作成・全社周知 |
| 全部署 | プロトコルに従ったIssue運用の開始 |

## 理由
- 全社的な可視性: ローカルファイルだけでは全体像が見えにくい
- PDCA追跡: フェーズラベルで進捗が一目瞭然
- 非同期情報共有: Issue上でのコメントで経緯が残る
- GitHub連携: コミットやPRとIssueを紐付け可能
