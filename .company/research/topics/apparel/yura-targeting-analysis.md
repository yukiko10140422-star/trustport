# YURA ターゲティング分析

## 目的

アパレルブランド「YURA」のターゲット顧客を定義し、Makuakeローンチからd2C展開に至るまでの顧客戦略の基盤を構築する。

## 前提（既存リサーチからの要約）


| 項目        | 内容                                         |
| --------- | ------------------------------------------ |
| ブランドコンセプト | 被災地×デジタルアーカイブ×アパレル。「記憶の揺らぎを力に変える」          |
| ミッション     | 災害の風化防止をファッションで実現                          |
| 主力商品      | 被災地の景観をアートプリントしたTシャツ                       |
| 価格帯       | 5,000〜8,000円                               |
| 寄付モデル     | 売上の10〜15%を復興支援に充当                          |
| ローンチ戦略    | Makuake CF → Shopify D2C → セレクトショップ・ポップアップ |
| 競合状況      | 「風化防止ファッション」カテゴリに直接競合なし（ブルーオーシャン）          |
| 製造候補      | 三恵クレア（福島・南相馬）、DTG/昇華転写印刷                   |

## 市場環境

### エシカルファッション市場（日本）


| 指標              | 数値             |
| --------------- | -------------- |
| 市場規模（2024年推計）   | 約1,500〜2,000億円 |
| 年間成長率           | 8〜12%          |
| アパレル市場全体に占める比率  | 約2%            |
| 「10〜20%高くても買う」層 | 消費者全体の約25〜30%  |
| エシカル消費を意識する消費者  | 約3割（消費者庁調査）    |


### プリントTシャツ市場


| 指標                 | 数値                                           |
| ------------------ | -------------------------------------------- |
| Tシャツ市場全体           | 約7,000億円                                     |
| オリジナル/カスタムTシャツ     | 現在500億円 → 2035年に1,200億円予測                    |
| アートプリントTシャツ（グローバル） | 54.2億USD（2024年）→ 120.6億USD（2031年）、CAGR 12.1% |


### 示唆

- エシカル×アートプリントの交差点は成長市場
- 5,000〜8,000円は「プレミアムだが許容範囲」の価格帯
- 日本国内で「地域風景×アートブランド」は空白地帯

```
  デザイン重視 ────────────┼──────────── ストーリー重視

```

---

### セグメントA: アーバンミレニアル（コアターゲット）


| 項目   | 詳細              |
| ---- | --------------- |
| 年齢   | 28〜38歳          |
| 性別   | 男女比 45:55       |
| 年収   | 400〜700万円       |
| 居住地  | 東京・大阪・名古屋など大都市圏 |
| 推定規模 | 300〜400万人       |


**行動特性:**

- SNS（Instagram, X）でトレンド情報を収集
- D2Cブランドの購買経験あり
- ブランドの「ストーリー」を重視して購入を判断
- 月1〜2回のオンラインファッション購入

**YURAへの共感ポイント:**

- 「着るアート」としてのデザイン性
- D2Cブランドへの親和性
- SNSで共有したくなるビジュアルとストーリー

**リーチ方法:**

- Instagram広告・インフルエンサーマーケティング
- D2C系メディア（TABI LABO, lifehacker等）
- Makuakeでの新商品発見

---

### セグメントB: ソーシャルコンシャス層（重要ターゲット）


| 項目   | 詳細        |
| ---- | --------- |
| 年齢   | 25〜45歳    |
| 性別   | 女性が約65%   |
| 年収   | 500万円以上   |
| 居住地  | 都市部中心     |
| 推定規模 | 150〜200万人 |


**行動特性:**

- エシカル消費・フェアトレード商品を積極的に選ぶ
- NPO支援・ボランティア参加経験がある
- 透明性（売上の使途開示）を重視
- 消費を通じた社会参加に価値を見出す

**YURAへの共感ポイント:**

- 「購入=風化防止への貢献」という明確な構造
- 売上の10〜15%が復興支援に充てられる透明性
- 一過性チャリティーではない継続的ブランド

**リーチ方法:**

- エシカル系メディア（ELEMINIST, IDEAS FOR GOOD等）
- ソーシャルグッド系イベント・マルシェ
- READYFOR/CAMPFIREのソーシャルグッドカテゴリ

---

### セグメントC: アート・カルチャー愛好層


| 項目   | 詳細           |
| ---- | ------------ |
| 年齢   | 25〜50歳       |
| 性別   | 男性がやや多い（55%） |
| 年収   | 600万円以上      |
| 居住地  | 都市部          |
| 推定規模 | 100〜150万人    |


**行動特性:**

- 美術館・ギャラリーに定期的に足を運ぶ
- 限定品・コラボアイテムへの関心が高い
- 「着るアート」としてのTシャツに価値を見出す
- デジタルアート・写真に造詣が深い

**YURAへの共感ポイント:**

- 被災地の景観をアートとして昇華するコンセプト
- 写真家コラボレーションによる作品性
- 限定コレクション・シーズン展開

**リーチ方法:**

- アート系メディア・ギャラリーとのコラボ
- 写真展・アートイベントでのポップアップ
- 限定エディションの訴求

---

### セグメントD: 被災地応援層（初期支援者として最重要）


| 項目   | 詳細               |
| ---- | ---------------- |
| 年齢   | 30〜60歳           |
| 性別   | 男女ほぼ均等           |
| 年収   | 問わない（応援消費の動機が強い） |
| 居住地  | 全国（特に被災地出身者・関係者） |
| 推定規模 | 200〜300万人（潜在層）   |


**行動特性:**

- ふるさと納税経験者が多い
- 被災地ボランティア経験あり
- 「風化させたくない」という強い感情的動機
- 災害追悼イベントに参加

**YURAへの共感ポイント:**

- 「風化防止」というミッションへの深い共感
- 被災地の美しい景観を通じた「記憶の継承」
- 地域経済への直接貢献（福島の製造パートナー）

**リーチ方法:**

- 被災地関連のNPO・団体との連携
- 災害追悼イベント・復興マルシェ
- ふるさと納税ポータルとの連携可能性
- 地方紙・地域メディアでのPR

## フェーズ別ターゲット戦略

### Phase 1: Makuakeローンチ（0〜3ヶ月）


| 項目      | 内容                                            |
| ------- | --------------------------------------------- |
| 優先ターゲット | セグメントD（被災地応援層）+ セグメントA（アーバンミレニアル）             |
| 目標金額    | 50〜100万円                                      |
| 目標支援者数  | 100〜200人                                      |
| リターン設計  | 早割3,980円 / 通常5,500円 / ペア9,800円 / 全色セット18,000円 |
| KPI     | 達成率200%以上、SNSシェア率15%以上                        |


**理由:** 被災地応援層は感情的動機が強く、初期支援者として最も確度が高い。同時にMakuakeのアーバンミレニアルユーザーにリーチし、D2Cフェーズの種を蒔く。

### Phase 2: D2C展開（3〜12ヶ月）


| 項目      | 内容                                      |
| ------- | --------------------------------------- |
| 優先ターゲット | セグメントA × B（コアターゲット）                     |
| チャネル    | Shopify自社EC                             |
| 集客手段    | Instagram広告、インフルエンサー、エシカル系メディアPR        |
| KPI     | 月間売上50万円、リピート率15%、Instagram フォロワー3,000人 |


### Phase 3: 拡大期（12ヶ月〜）


| 項目      | 内容                              |
| ------- | ------------------------------- |
| 拡大ターゲット | セグメントC（アートカルチャー層）を本格取り込み        |
| チャネル    | セレクトショップ卸、ポップアップ、被災地メモリアル施設での販売 |
| 施策      | 写真家コラボ限定エディション、アート展との連携         |
| KPI     | 月間売上150万円、取扱店舗5店舗、メディア掲載月2件     |

## リスクと対策


| リスク                 | 影響             | 対策                           |
| ------------------- | -------------- | ---------------------------- |
| 「チャリティーTシャツ」と同一視される | デザイン性・ブランド性の毀損 | アート性を最優先。「チャリティー」という言葉を使わない  |
| 被災地への「消費」という批判      | SNS炎上リスク       | 被災地の方々との共創プロセスを透明化。当事者の声を前面に |
| ご当地Tシャツとの混同         | 価格正当化が困難に      | プリント品質・素材・ブランディングで明確に差別化     |
| 災害発生時のセンシティビティ      | 販売・PRの自粛判断     | 新災害発生時のコミュニケーションガイドラインを事前策定  |
