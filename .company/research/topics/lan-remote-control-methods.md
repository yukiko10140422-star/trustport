# LAN内リモートPC操作 技術調査

- **調査日**: 2026-03-12
- **担当**: リサーチ部 深山蒼
- **依頼元**: オーナー（秘書室経由）
- **ステータス**: 完了

## 概要

同一WiFi（ローカルネットワーク）内でPCをリモート操作する方法を網羅的に調査。
OS標準機能、無料/OSS、有料ツール、ターミナル系、ブラウザ系の5カテゴリで整理。

---

## 1. OS標準機能

### Windows リモートデスクトップ (RDP)

| 項目 | 内容 |
|------|------|
| セットアップ | 簡単（設定からONにするだけ） |
| 対応OS | **ホスト: Windows Pro/Enterprise のみ**（Home不可）。クライアント: 全Windows |
| 費用 | 無料（OS付属） |
| セキュリティ | 暗号化済み、NLA認証対応 |
| 性能 | 非常に良い（描画コマンド送信で帯域効率高い） |

> 注意: Windows Home ユーザーはRDPホスト不可。「RDP Wrapper Library」は非公式で不安定。

### macOS 画面共有

| 項目 | 内容 |
|------|------|
| セットアップ | 簡単（システム設定 > 共有 > 画面共有ON） |
| 対応OS | macOS同士。VNC互換あり |
| 費用 | 無料 |
| 性能 | LAN内であれば良好 |

### Linux GNOME Remote Desktop

| 項目 | 内容 |
|------|------|
| セットアップ | 中級者向け |
| 対応OS | Ubuntu 22.04+はRDP対応標準搭載 |
| 費用 | 無料 |

## 2. 無料ツール / OSS

### RustDesk ★最推奨

| 項目 | 内容 |
|------|------|
| セットアップ | 簡単（インストールだけでP2P接続可能） |
| 対応OS | Windows, macOS, Linux, Android, iOS |
| LAN/WAN | 両方対応。自前サーバーで完全自己管理も可 |
| 費用 | 完全無料・OSS |
| セキュリティ | E2E暗号化（NaCl）。セルフホスト対応 |
| 性能 | 良好（Rust製で軽量） |
| URL | https://rustdesk.com/ |

> TeamViewerの完全なOSS代替。Windows Home ユーザーに最善の選択肢。

### Moonlight + Sunshine ★低遅延用途に最適

| 項目 | 内容 |
|------|------|
| セットアップ | 中程度（サーバー: Sunshine / クライアント: Moonlight） |
| 対応OS | 全プラットフォーム対応 |
| LAN/WAN | **LAN特化で最高性能**（3-5msの超低遅延） |
| 費用 | 完全無料・OSS |
| 性能 | **最高クラス**（4K/120FPS対応、GPU HWエンコード） |

> 映像品質・低遅延重視のクリエイティブ/ゲーミング用途に最適。

### VNC系（TigerVNC / TightVNC / RealVNC）

| 項目 | 内容 |
|------|------|
| セットアップ | 中程度 |
| 対応OS | クロスプラットフォーム |
| 費用 | TigerVNC/TightVNCは無料 |
| セキュリティ | **VNC単体は暗号化なし** → SSHトンネル併用必須 |
| 性能 | RDPより劣る（画面全体をビットマップ転送） |

## セキュリティ注意事項

1. VNC単体は暗号化なし → SSHトンネルと併用するか、RDP/RustDesk等の暗号化対応ツールを使う
2. RDP(3389)を外部に直接公開しない → ブルートフォース攻撃の標的になる
3. Chrome リモートデスクトップはGoogleサーバー経由 → 機密性の高い業務には注意
4. TeamViewer/AnyDeskの無人アクセス → 強力なパスワードと2FAを必ず設定
5. セルフホスト型（RustDesk, Guacamole）が最もプライバシーを確保できる
