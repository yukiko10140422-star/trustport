## 1. デジタル化・AI導入補助金2026の詳細

### 1.1 制度概要

2026年度より、従来の「IT導入補助金」は **「デジタル化・AI導入補助金」** に名称変更。AI活用や業務変革につながる取り組みをより重視する制度設計に移行した。

- 公式サイト: https://it-shien.smrj.go.jp/
- 運営: 中小企業基盤整備機構（SMRJ）

### 1.2 申請枠の詳細

#### (A) 通常枠

| 項目 | 内容 |
|------|------|
| **補助率** | 1/2以内（小規模事業者は2/3以内） |
| **補助額（1プロセス以上）** | 5万円〜150万円未満 |
| **補助額（4プロセス以上）** | 150万円〜450万円以下 |
| **要件** | 業務プロセスを保有するソフトウェアを1種類以上選択 |

- 2026年度からは「AI機能あり」のITツールが制度上で明確に区分される
- 生成AI、機械学習、自動化機能を備えたツールが評価されやすくなる

#### (B) インボイス枠（インボイス対応類型）

| 項目 | 内容 |
|------|------|
| **補助率（ソフトウェア）** | 2/3以内 |
| **補助率（50万円以下部分）** | 3/4以内 |
| **補助率（小規模事業者・50万円以下）** | 4/5以内 |
| **補助率（ハードウェア）** | 1/2以内 |
| **補助額上限** | 最大350万円 |
| **要件** | 会計・受発注・決済のうち2機能以上選択必須 |
| **対象経費** | ソフトウェア購入費、導入関連費、PC・タブレット・レジ等ハードウェア |

#### (C) セキュリティ対策推進枠

| 項目 | 内容 |
|------|------|
| **補助率** | 1/2以内（小規模事業者は2/3以内） |
| **補助額** | 5万円〜150万円 |
| **要件** | 「サイバーセキュリティお助け隊サービスリスト」掲載サービスの導入 |
| **補助期間** | 最大2年分 |

#### (D) 複数社連携デジタル化・AI導入枠

| 項目 | 内容 |
|------|------|
| **補助率（ソフトウェア・50万円以下）** | 3/4〜4/5 |
| **補助率（その他）** | 2/3〜3/4 |
| **補助額上限** | 最大3,000万円 |
| **要件** | 10者以上の中小企業が連携 |
| **対象** | インボイス対応、キャッシュレス導入、消費動向分析等 |

### 1.4 IT導入支援事業者（ベンダー）登録

#### 登録形態

| 形態 | 概要 |
|------|------|
| **法人（単独）** | 全要件を満たす法人が単独で登録 |
| **コンソーシアム** | 幹事社1社＋構成員で登録。個人事業主も構成員として参画可能 |

#### 法人登録の主要要件（21項目）

- 日本国内で法人登記され、日本国内で事業を営む法人であること
- 安定的な事業基盤を有していること
- **ITツールの販売実績があること**（最大のハードル）
- 履歴事項全部証明書の提出
- 法人税の納税証明書の提出
- 過去に補助金に関わる不正行為等がないこと

#### スタートアップがベンダー登録するためのハードル

1. **販売実績要件**: 法人登録では販売実績が必須。設立年数の明示的な制限はないが、実績のない企業は登録困難
2. **回避策**: **コンソーシアム登録を活用** — 構成員としてなら販売実績不要・個人事業主も可
3. **実績のある幹事社と組む**: 既存のIT導入支援事業者を幹事社としてコンソーシアムを組成するのが現実的な参入経路

#### 登録スケジュール

- **2026年1月30日〜**: 事前登録受付開始（2024年度ベンダー登録者対象）
- **2026年3月31日〜**: 新規登録申請開始（見込み）

### 1.5 DXソフト事業への示唆

- **通常枠**: DXソフトが業務プロセス対応であれば最大450万円の補助。顧客の実質負担を半減できる強力な営業ツール
- **インボイス枠**: 会計・受発注機能があれば最大350万円、小規模事業者は実質負担1/5〜1/4
- **ベンダー登録戦略**: まずコンソーシアム構成員として参入し、実績を積んでから単独法人登録を目指すのが合理的

## 2. 商工会議所チャネルの実態

### 2.1 規模と概要

| 項目 | 数値 |
|------|------|
| **全国の商工会議所数** | 515 |
| **会員企業数** | 約126万事業者 |
| **設立** | 1922年（大正11年） |
| **法的根拠** | 商工会議所法に基づく民間の地域総合経済団体 |

- 各商工会議所は独立した組織として運営
- 日本商工会議所が全国の連合会組織として機能

### 2.2 商工会議所が提供するDX支援プログラム

#### 東京商工会議所（先進事例）

| プログラム名 | 内容 |
|-------------|------|
| **デジタルサービスぴったりナビ** | 中小企業とITベンダーのマッチングツール |
| **デジタルサポートプレミアム** | 東商会員優待付きデジタルツール・サービスの提供 |
| **デジタル活用・DX事例集** | 成功事例の共有・啓蒙 |
| **生成AI活用ガイド** | AI導入の基礎知識提供 |
| **DX推進セミナー** | 生成AI関連セミナー等 |

#### 他地域の取り組み

- **神戸商工会議所**: DX支援事業として会員企業のデジタル化・DX導入を支援、AI活用セミナー実施
- **札幌商工会議所**: DXビジネスサポートプログラム（1対1のカスタマイズ支援）
- **川口商工会議所**: DXデジタル支援事業（IT化推進・人材育成支援）

### 2.3 DXツール導入事例（商工会議所経由）

| 企業名 | 導入内容 | 効果 |
|--------|---------|------|
| バキュームモールド工業（株） | プログラミング不要の開発ツール導入 | 社員が自ら業務アプリ開発、現場課題解決 |
| 八大（株） | 車両管理・点呼デジタル化、業務クラウドシステム共同開発 | 業務効率化・経営データの見える化 |

### 2.4 商工会議所と連携するために必要なステップ

1. **地元商工会議所への会員加入**: まず所在地の商工会議所に入会（年会費は企業規模に応じて数万円〜）
2. **DX支援担当者との関係構築**: 経営指導員やIT支援担当者にツールを紹介
3. **東商「デジタルサポートプレミアム」等への掲載申請**: ITベンダーとして会員優待サービスに登録
4. **セミナー・展示会への出展**: 商工会議所主催のDXセミナーで登壇・出展
5. **「ぴったりナビ」への登録**: 東京商工会議所のマッチングプラットフォームに登録
6. **日本商工会議所との連携提案**: 全国展開を目指す場合、日商のデジタル化推進部門にアプローチ

### 2.5 DXソフト事業への示唆

- **126万事業者への間接リーチ**: 商工会議所を通じて中小企業にアプローチ可能
- **信用力の担保**: 商工会議所推奨ツールとして認知されればCACを大幅に低減
- **地域密着型展開**: まず地元の商工会議所で実績を作り、横展開するのが効果的
- **ITベンダーも会員参画可能**: 東京商工会議所はITベンダーの会員参画を明示的に歓迎

## 3. 税理士・会計事務所パートナーシップ

### 3.1 日本の税理士事務所の規模

| 項目 | 数値（2025年12月末現在） |
|------|--------------------------|
| **税理士登録者数** | 82,276人 |
| **税理士法人の届出数** | 8,269事務所（主＋従） |
| **増加傾向** | 長期的に増加も、直近は純増数が9年ぶりに500人を割る鈍化傾向 |

- 参考推移: 1990年 57,073人 → 2020年 79,404人 → 2025年 82,276人

### 3.2 税理士がDXツールを顧客に勧める動機・インセンティブ

| 動機 | 詳細 |
|------|------|
| **業務効率化** | クラウド会計導入で記帳代行の工数削減、本来の付加価値業務に注力可能 |
| **顧問先の経営支援** | リアルタイムの財務データで経営アドバイスの質向上 |
| **新規顧問先獲得** | DX対応を打ち出すことで若い経営者層を獲得 |
| **パートナー収益** | freee・マネーフォワード等のパートナープログラムからの報酬 |
| **差別化** | DX対応事務所として市場での競争優位を確保 |

### 3.3 freee 認定アドバイザー制度

#### 制度概要

会計事務所とfreeeがパートナーシップを形成し、スモールビジネスの成功を支援するプログラム。

#### プラン構成

| プラン | 年会費 | 主な特典 |
|--------|--------|---------|
| **シンプルプラン** | 49,800円/年（税抜） | 税理士検索サイト無料掲載、基本特典 |
| **プライムプラン** | 357,600円/年（税抜） | ランクに応じた報酬支払、充実サポート |

#### ランク制度・インセンティブ

- freee導入スコアと保有資格数により**5段階のランク**を用意
- ランクに応じた**収益特典（報酬支払）**を提供
- 認定アドバイザーになるには: アドバイザー制度加入 + freee個人認定資格1種類以上 + 3件以上の顧問先にfreee導入

#### 顧問先向け料金

- 記帳代行プラン: 月1,000円/社
- 自社用: 会計・人事労務ソフト、ストレージ、AI-OCR使い放題

#### 掲載事務所数

- freee税理士検索: **2,000以上の事務所が掲載**

### 3.4 マネーフォワード クラウド公認メンバー制度

#### 規模

- 全国 **50,000名超** の士業事務所が登録
- TOP500会計事務所の中で導入数No.1

#### パートナーランク

| ランク | 入会金 | 年会費 | 条件 |
|--------|--------|--------|------|
| **ブロンズ** | なし | 0円 | なし |

| **プラチナ** | ランクアップのみ | 50万円 | 利用社数30社以上 |

#### 収益特典

| ランク | 導入報酬 | クレジットカード課金報酬 |
|--------|---------|------------------------|
| **シルバー** | 5万円〜 | - |
| **ゴールド** | あり | 課金額の8% |

#### その他の特典

- 顧問先用アカウント5社分（シルバー以上）
- 専任サポートチームによる定着支援（シルバー以上）

- ロゴ・バナー・ノベルティ提供

### 3.5 税理士チャネルの顧客獲得コスト（CAC）

直接的な税理士チャネルのCAC公開データは限定的だが、以下の推定が可能:

| 指標 | 推定値 | 備考 |
|------|--------|------|
| **紹介経由のCAC** | 直接営業の1/3〜1/5 | 紹介はコンバージョン率が高く、SaaS業界の一般的傾向 |
| **SaaS健全指標** | LTV/CAC > 3.0 | 税理士紹介チャネルはこの基準を満たしやすい |
| **パートナー構築コスト** | 初年度10万〜50万円/事務所 | セミナー・教育・サポートの総合コスト |
| **スケール後のCAC** | 数千円〜1万円/顧客 | 紹介フローが定着した後の限界コスト |

- freee・マネーフォワードのモデル: パートナープログラム費用（年会費）＋営業人件費で税理士を獲得し、税理士経由で顧問先を低CACで獲得するTwo-Sided構造
- 税理士1人あたりの平均顧問先数は20〜50社であり、1税理士パートナーから複数顧客を獲得可能

### 3.6 DXソフト事業への示唆

- **82,000人超の税理士ネットワーク**: 巨大な間接チャネル
- **freee/MFのパートナーモデルを参考**: ランク制＋報酬支払で段階的にエンゲージメント
- **参入障壁**: 既にfreee/MFが強固なパートナー網を構築済み。差別化（業種特化、AI機能等）が必要
- **ブロンズ（無料）から始めるモデル**: マネーフォワード型の無料参入→実績ベースのランクアップは参考になる

## 4. 地方自治体のDX支援制度

### 4.1 国の主要制度

#### (A) デジタル田園都市国家構想交付金 → 「新しい地方経済・生活環境創生交付金（第2世代交付金）」

| 項目 | 内容 |
|------|------|
| **背景** | 「地方創生2.0」の下、デジタル田園都市国家構想交付金が再編 |
| **予算規模** | 2025年度予算 2,000億円（前年比倍増）、補正予算含め3,000億円 |
| **2026年度** | 概算要求に計上済み、継続見込み |

#### 支援対象

- 地方公共団体の自主性と創意工夫に基づく地域独自の取り組み
- デジタル技術を活用した地域課題解決・魅力向上
- 複数地方公共団体によるデジタル技術の共同利用
- 先進的な防災の取り組み
- 半導体等戦略分野の産業拠点整備

#### (B) デジタル基盤改革支援補助金

| 項目 | 内容 |
|------|------|
| **対象** | 自治体向け |
| **支援内容** | 業務効率化・住民利便性向上アプリ、クラウドサービス導入費用、データ連携基盤構築、マイナンバーカード高度利用 |

#### (C) 総務省「地域社会DXのトビラ」支援メニュー

- 地域社会のデジタル化推進を支援
- 自治体DX推進計画の策定・実行支援
- デジタル人材育成支援

### 4.2 自治体独自のDX支援制度

| 自治体 | 制度名 | 概要 |
|--------|--------|------|
| **東京都** | デジタル技術活用推進事業 | 都内中小企業のデジタル技術導入支援 |
| **大阪府** | DX推進補助金 | 府内企業のDX推進を補助 |
| **静岡市** | 中小企業等DX支援業務 | 顧客管理・販路開拓・社内情報共有等のDX支援（公募型プロポーザル） |
| **その他** | 各自治体の産業振興課が独自制度を運営 | 国の補助金と併用可能な制度も多い |

### 4.3 自治体DX推進計画

- 総務省「自治体DX推進計画 第4.0版」（2025年3月28日策定）
- 2026年度までの計画として全自治体に策定を求めている
- 自治体自身のDX（行政手続オンライン化等）と、自治体が地域企業のDXを支援する両面がある

### 4.4 DXソフト事業への示唆

- **自治体の公募型プロポーザルに参加**: 静岡市のように自治体がDX支援ベンダーを公募するケースが増加
- **地方創生交付金の活用**: 自治体がDXツール導入に交付金を充当する際のベンダーとして採択を目指す
- **予算規模3,000億円**: 地方創生関連のデジタル投資は大規模で、参入余地あり
- **国の補助金＋自治体独自補助の併用**: 顧客の実質負担をさらに低減可能

## 5. よろず支援拠点について

### 5.1 基本情報

| 項目 | 内容 |
|------|------|
| **設置根拠** | 経済産業省が設置 |
| **運営** | 独立行政法人 中小企業基盤整備機構（SMRJ） |
| **拠点数** | **全国47都道府県に各1拠点以上**（＋サテライト拠点あり） |
| **利用料** | 完全無料（何度でも相談可能） |

### 5.2 相談件数の推移

| 年度 | 相談件数 |
|------|---------|
| 2014年 | 約66,000件 |
| 2021年 | **約460,000件**（7年で約7倍） |
| 満足度 | 約9割が「満足・やや満足」と回答 |

### 5.3 相談内容の内訳（令和3年度）

| カテゴリ | 割合 |
|---------|------|
| 売上拡大 | 約70% |
| 経営改善・事業再生 | 約18% |
| 創業 | 約11% |
| 事業承継 | 約1.5% |

### 5.4 DX関連の相談トレンド

- 課題別検索項目に「IT活用」が含まれている
- 中小企業支援機関（商工会、商工会議所、よろず支援拠点を含む）における**デジタル化に関する相談件数は約6割の機関で「増加」**と回答（2023年対比）
- 約7割が相談に対する課題解決について「ほぼ全て解決できている」又は「やや解決できている」と回答
- IT・DX相談は「売上拡大」の一部としてカウントされることも多く、実態の割合はさらに大きい可能性

### 5.5 ツールベンダーとの連携実態

- よろず支援拠点自体がツールベンダーと直接的なパートナーシップを持つ仕組みは**公式には確認されていない**
- 相談員がツールを推奨する場合は、個別の判断で行われている
- ただし、相談員の中にはIT専門家が含まれており、ツール選定のアドバイスを提供するケースは多い
- 他の支援機関（商工会議所、金融機関等）への紹介機能があり、間接的にベンダーに繋がるケースもある

### 5.6 DXソフト事業への示唆

- **年間46万件の相談**: 巨大なリード源。DX関連相談の増加トレンドは追い風
- **直接パートナーシップは困難**: 公的機関のため、特定ベンダーの推奨は制度上難しい
- **相談員へのアプローチ**: IT専門相談員にツールを認知してもらうことで、間接的な紹介を期待
- **セミナー登壇**: よろず支援拠点が主催するDXセミナーへの登壇依頼は有効な接点
