# 計画管理ルール

## 計画ディレクトリ

プロジェクトルートの `plans/` ディレクトリで計画を管理する。

```
plans/
├── README.md      ← 運用ルール・テンプレート
├── pending/       ← 未着手・進行中
└── finished/      ← 完了済み
```

## セッション開始時

1. `plans/pending/` を確認し、未完了の計画を把握する
2. 優先度 HIGH の計画を最優先で処理する
3. ユーザーの指示と計画の整合性を確認する

## 新しい計画の作成

- `/plan` コマンドまたは大きなタスクの議論後に作成する
- ファイル名: `YYYY-MM-DD-<slug>.md`
- テンプレートは `plans/README.md` を参照
- 必ずチェックリスト形式で進捗管理する

## 計画の完了

- 全チェック項目が完了したら `pending/` → `finished/` に移動する
- 完了日を記入する
- 関連コミットハッシュがあれば記録する

## 計画と他ツールの関係

| 場面 | 使うもの |
|------|---------|
| セッション内のタスク進捗 | TodoWrite（タスクリスト） |
| セッションをまたぐ計画 | `plans/pending/` のMDファイル |
| 将来の会話で必要な情報 | memory（`~/.claude/projects/` 配下） |
| コードの規約・チェックリスト | rules（`.claude/rules/` 配下） |
